# VoltWise – Smart EV Buyer's Assistant

## About the Project
VoltWise is a web-based assistant that helps users explore and compare Electric Vehicles (EVs).

## Features
- Explore electric vehicles.
- Filter vehicles by budget and category.
- Compare different EV models.
- Ask questions using the EV chatbot.
- Learn about EV range, charging, battery capacity and maintenance.

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript

## How to Run
1. Install Python.
2. Install dependencies using `pip install -r requirements.txt`.
3. Run `python app.py`.
4. Open `http://127.0.0.1:5000` in your browser.

## Project Type
EV information and comparison web application.
